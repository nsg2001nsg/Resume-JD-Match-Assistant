# Model Report

## Scope

This report evaluates the logistic regression model against `silver_dataset.csv`.
The labels are silver labels generated by the project pipeline, not real hiring outcomes.

## Dataset

- Rows: 7480
- Label counts: {'0': 6317, '1': 1163}
- Unique resumes: 2399
- Unique JDs: 72
- Features: tfidf_similarity, keyword_overlap_ratio, education_level_score, experience_gap

## Metrics

- Dummy baseline accuracy: 0.8443
- Row split accuracy: 0.9953
- Row split ROC-AUC: 0.9998
- Resume-group holdout accuracy: 0.9926
- Resume-group holdout ROC-AUC: 0.9999

## Feature Coefficients

- `tfidf_similarity`: 6.5771
- `keyword_overlap_ratio`: 1.1188
- `education_level_score`: -0.1350
- `experience_gap`: 0.4310

## Limitations

- Training labels are silver labels generated from matching heuristics.
- Metrics should be described as silver-label validation, not hiring accuracy.
- External labeled pair validation is tracked separately.
